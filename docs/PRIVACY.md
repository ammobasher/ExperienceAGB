# Privacy and local data lifecycle

- This is a static browser application. Local files are read and parsed by a local Web Worker; deterministic analysis stays in that browser.
- The approved release is **local-only hosting** on loopback. The owner authorized publishing only the bundled demonstration sample, not private exports, profiles, identities or test evidence. Repository publication is not permission to deploy a public model-upload service.
- Model/profile data is kept only in page/worker memory. There is no localStorage/sessionStorage/IndexedDB persistence, recents list, telemetry, account, server storage, or model-upload endpoint.
- Loading the bundled sample fetches a static file from the application's own origin. Application assets and the worker are also same-origin requests. In development, Vite uses its ordinary local development connection.
- **Open another**, import cancellation, recovery, reload, or leaving the page disposes of the active worker and/or workspace. This is an application lifecycle statement, not a secure memory-erasure guarantee; browser/OS memory and user-controlled extensions are outside the app's control.
- Optional AI context preview is **local only**. GitHub Models, selected in the original plan, retired July 30, 2026; its production guard sends nothing, regardless of token or consent. There is no alternative provider, catalog lookup or inference call. The proposed destination/payload and separate profile-value consent are visible without transmission. See [AI](AI.md) for the blocker and exact preview/harness limits.
- Do not enter real credentials for a retired service. Credential-handling controls and injected transport tests never persist credentials in browser storage, URLs or logs. Forget/disable, workspace close/replacement and reload clear the application reference and consent; this is not secure browser/OS memory erasure.
- A future supported integration requires separately approved destination, current contract, organization/provider terms and live nonsensitive CORS/entitlement checks. Minimization cannot guarantee anonymity of numerical patterns or separately consented feature/value context. Provider retention/training rules are outside local control; mocked tests do not invent approval.
- GitHub Copilot is the owner's requested future default, but an official SDK/CLI loopback bridge is not yet authorized or implemented. This release does not collect a Copilot key, use an internal endpoint, change stored authentication or send context to Copilot.
- Render-failure logging uses a generic message without model/profile content. User-visible diagnostics include local JSON paths and model facts; do not paste sensitive exports into public issues.
- Standard browser extensions, devtools, screenshots, host access logs, and third-party hosting infrastructure can have their own data policies. Use a trusted browser/device and approved hosting.

Runtime tests check that opening/tracing a model does not create persisted app state. A scoped loopback-only review observed no model upload. These checks are not a full security/privacy certification; a formal review remains a release gate.
